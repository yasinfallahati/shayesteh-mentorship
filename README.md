# منتورشیپ شایسته

سامانه پیش‌ثبت‌نام، آموزش ویدیویی، آزمون و اشتراک ماهانه شرکت تجارت الکترونیک شایسته ایرانیان.

## اجرا روی سیستم توسعه

```bash
npm install
cp .env.example .env.local   # مقدار ADMIN_PASSWORD را عوض کنید
npm run dev
```

- سایت: `http://localhost:3000`
- پنل هنرجو: `/login`
- پنل سوپرادمین: `/admin/login`

برای دیدن همه صفحه‌ها با داده نمایشی:

```bash
npm run seed:demo
```

نام‌های کاربری و رمز نمایشی بالای فایل `scripts/seed-demo.ts` نوشته شده‌اند. این دستور را روی سایت واقعی اجرا نکنید.

## راه‌اندازی روی سرور

```bash
npm ci
npm run build
npm start
```

- Node.js نسخه ۲۰ یا بالاتر لازم است. برای ساخت نمونه ویدیوی نمایشی به ffmpeg هم نیاز است.
- `ADMIN_PASSWORD` فقط در اولین اجرا خوانده می‌شود. بعد از آن رمز را از تنظیمات پنل سوپرادمین عوض کنید.
- دیتابیس و همه فایل‌های آپلودی در پوشه `DATA_DIR` هستند. از این پوشه مرتب نسخه پشتیبان بگیرید.
- پشت Nginx این تنظیمات لازم است تا آپلود ویدیو و محدودیت تلاش ورود درست کار کنند:

```nginx
client_max_body_size 8G;
proxy_request_buffering off;
proxy_read_timeout 3600s;
proxy_set_header X-Real-IP $remote_addr;
proxy_set_header X-Forwarded-Proto $scheme;
```

## قواعد اشتراک

- هر پرداخت تاییدشده ۳۰ روز اشتراک می‌دهد.
- بعد از پایان اشتراک ۱۰ روز مهلت هست و پنل باز می‌ماند.
- تمدید در زمان مهلت از تاریخ پایان قبلی حساب می‌شود، و بعد از غیرفعال شدن پنل از روز تایید.
- منطق این قواعد در `src/lib/subscription.ts` است و با `npm test` بررسی می‌شود.
